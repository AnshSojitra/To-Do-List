# To-Do List

A simple browser-based to-do list application for creating, editing, completing, and deleting tasks.

## Features

- Add tasks by clicking **Add** or pressing Enter
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Automatically save tasks in the browser using `localStorage`

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/AnshSojitra/To-Do-List.git
   ```
2. Open `index.html` in your browser.

No build tools or dependencies are required.

## Project Structure

- `index.html` - Application markup
- `script.js` - Task management and persistence logic
- `style.css` - Application styling
- `README.md` - Project documentation
